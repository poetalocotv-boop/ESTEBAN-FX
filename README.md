# ESTEBAN FX

Plataforma personal de análisis técnico multi-gráfico + MetaTrader 5 Web.

## Características

- Hasta **20 gráficos de TradingView** al mismo tiempo
- Cada gráfico es un widget completo (puedes cambiar símbolo, timeframe, indicadores…)
- Barra superior de **operaciones abiertas** (datos de ejemplo – editable)
- Panel inferior de **MetaTrader 5 Web Terminal** (configurable con la URL de tu broker)
- Diseño único en tonos neón (cyan, rosa, naranja, verde)
- 100% frontend – no necesita backend

## Cómo usar

1. Abre el `index.html` o despliega en Vercel / Netlify / GitHub Pages
2. Cambia los símbolos de los gráficos escribiendo en el cuadro de cada uno (ej: `FX:EURUSD`, `OANDA:XAUUSD`, `BINANCE:BTCUSDT`)
3. Añade más gráficos con el botón **+ Añadir Gráfico**
4. Abre el panel MT5 y pega la URL del terminal web de tu broker
5. Las operaciones abiertas son de ejemplo – puedes editarlas en el código o conectar una API más adelante

## Despliegue rápido en Vercel

1. Ve a [vercel.com](https://vercel.com)
2. Importa este repositorio
3. Deploy (no necesita configuración extra)
